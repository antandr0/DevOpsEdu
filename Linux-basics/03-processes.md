# 2.3. Процессы и службы (systemctl)

**Процесс** — это запущенная программа.
**`systemd`** — главный менеджер (система инициализации) в Linux, который запускает службы.

## Основные команды `systemctl`
- `systemctl status <имя>` — статус службы.
- `systemctl start <имя>` — запустить (сейчас).
- `systemctl stop <имя>` — остановить.
- `systemctl restart <имя>` — перезапустить.
- `systemctl enable <имя>` — добавить в автозагрузку (при старте системы).
- `systemctl disable <имя>` — убрать из автозагрузки.

## Просмотр процессов
- `top` или `htop` — диспетчер задач в реальном времени.
- `ps aux` — снимок всех процессов.
