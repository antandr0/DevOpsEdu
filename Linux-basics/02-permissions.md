# 2.2. Права доступа

## Типы прав (rwx)
- `r` (read) — чтение (4)
- `w` (write) — запись (2)
- `x` (execute) — выполнение (1)

## Категории пользователей (ugo)
- `u` (user) — владелец
- `g` (group) — группа
- `o` (others) — остальные

## Изменение прав (chmod)
Цифровой метод: `chmod 755 file.txt`
- Владелец: 7 (4+2+1 = rwx)
- Группа: 5 (4+1 = r-x)
- Остальные: 5 (4+1 = r-x)
Добавление выполнения: `chmod +x script.sh`

## Изменение владельца (chown)
`chown user:group file.txt`

## Суперпользователь (sudo)
`sudo` позволяет выполнять команды с правами `root` (администратора).
