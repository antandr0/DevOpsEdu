# 2.1. Файловая система и навигация

В Linux нет дисков (C:, D:). Вся система представляет собой единое дерево, начинающееся с корня `/`.

## Основные директории
- `/` — Корень системы.
- `/home` — Домашние папки пользователей (например, `/home/serv2`). Обозначается `~`.
- `/etc` — Конфигурационные файлы (настройки).
- `/var/log` — Журналы событий (логи).
- `/bin` и `/usr/bin` — Исполняемые файлы (программы).

## Основные команды
- `pwd` — показать текущую папку.
- `ls` — показать содержимое папки (`ls -l`, `ls -a`).
- `cd` — переход в папку (`cd /etc`, `cd ~`, `cd ..`).
- `cat` — вывод содержимого файла.
