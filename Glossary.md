# Глоссарий терминов

**SSH (Secure Shell)** — сетевой протокол для безопасного удаленного управления сервером.
**Port Forwarding** — перенаправление портов, позволяющее получить доступ к сервису внутри локальной сети извне.
**NAT (Network Address Translation)** — механизм трансляции сетевых адресов, скрывающий внутреннюю сеть за одним внешним IP.
**`sudo` (Superuser DO)** — утилита, позволяющая обычному пользователю выполнять команды с правами суперпользователя (root).
**`chmod` (Change Mode)** — команда для изменения прав доступа к файлам и папкам.
**`chown` (Change Owner)** — команда для изменения владельца файла или папки.
**`root`** — суперпользователь в Linux, имеющий неограниченный доступ ко всем файлам и настройкам системы.
**Права доступа** — правила, определяющие, кто и что может делать с файлом (чтение `r`, запись `w`, выполнение `x`).
