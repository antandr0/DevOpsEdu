# Шаг 1. SSH и удаленный доступ

## Что такое SSH
SSH (Secure Shell) — протокол для безопасного подключения к удаленному серверу.

## Проброс портов (Port Forwarding)
Так как ВМ находится за NAT, мы настроили проброс порта с основного ПК (порт 2222) на ВМ (порт 22). 
Команда подключения: `ssh -p 2222 serv2@127.0.0.1`

## SSH-ключи
Для безопасного входа без пароля используются ключи.
- `ssh-keygen -t ed25519` — генерация ключей.
- `ssh-copy-id -p 2222 serv2@127.0.0.1` — копирование ключа на сервер.

## Конфигурация SSH
Главный файл настроек: `/etc/ssh/sshd_config`. (Также вложенные файлы в `/etc/ssh/sshd_config.d/`).
Важный параметр: `PasswordAuthentication` (вход по паролю).
